# FTP upload (GLR/Plesk)

Deze opdracht staat in:

- `projectweek3/program2`

Gebruik in VS Code de SFTP extensie met config uit:

- `.vscode/sftp.json`

## Belangrijk

- Vul in `.vscode/sftp.json` nog je eigen `password` in.
- `remotePath` staat op `/httpdocs/projectweek3/program2` zodat deze map direct online staat.

## Public URL

Na upload is de opdracht bereikbaar via:

- `https://102227.stu.sd-lab.nl/projectweek3/program2/`

## Checklijst

1. Upload projectmap via SFTP.
2. Open URL en test:
   - indexpagina
   - opdracht1.php
   - opdracht2.php
3. Controleer of alle links en styles werken.
